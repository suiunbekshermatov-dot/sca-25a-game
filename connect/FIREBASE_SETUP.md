# ITBC Connect — настройка Firebase

Эта папка содержит интерфейс ITBC Connect. Чтобы сообщения и рейтинг работали у всех кураторов, нужен отдельный проект Firebase, созданный в аккаунте колледжа.

## Шаг 1. Создать проект
1. Откройте https://console.firebase.google.com/
2. Нажмите **Create a project / Создать проект**.
3. Название: `ITBC-Connect`.
4. Google Analytics можно пока отключить.
5. Нажмите **Create project**.

## Шаг 2. Добавить веб-приложение
1. В обзоре проекта нажмите значок веб-приложения `</>`.
2. Имя приложения: `ITBC Connect Web`.
3. Зарегистрируйте приложение.
4. Firebase покажет объект `firebaseConfig` с полями `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`.
5. Эти значения нужны для подключения сайта. Не отправляйте пароли Google, приватные ключи сервисных аккаунтов или закрытые токены.

## Шаг 3. Включить вход
1. Откройте **Build → Authentication → Get started**.
2. В **Sign-in method** включите **Email/Password**.
3. Не разрешайте свободную регистрацию кураторов на публичной странице. Аккаунты должен создавать администратор.

## Шаг 4. Создать базу данных
1. Откройте **Build → Firestore Database → Create database**.
2. Выберите production mode.
3. Выберите ближайший доступный регион, согласованный с требованиями колледжа.
4. Не включайте открытые правила вида `allow read, write: if true;`.

## Шаг 5. Дальнейшее подключение
После выполнения шагов пришлите скриншот обзора проекта Firebase или скриншот блока `firebaseConfig` (можно закрыть значения, если предпочитаете). Не присылайте пароль Google. Затем можно связать сайт с проектом и проверить вход, сообщения и межгрупповые вызовы.

## Что пока не работает
Пока конфигурация Firebase не подключена, вход на сайте демонстрационный. Никакие реальные аккаунты, сообщения или баллы не создаются и не синхронизируются.
